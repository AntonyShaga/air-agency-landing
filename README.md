# Air Agency Landing Page

A landing page for the Air creative agency, created to showcase the agency, its services, expertise, testimonials, and contact information.

## Project Description

The Air Agency Landing Page is a single-page website designed to present a full-service creative agency and provide visitors with information about its approach, expertise, services, and client feedback. It includes sections for agency information, areas of expertise, service offerings, testimonials, and contact details. The page also features an interactive hero slider and a contact form.

## Technical Requirements

To run this project, you will need:

* **Node.js** (version 14.x or newer): A JavaScript runtime built on Chrome's V8 JavaScript engine, used for running the development environment and project scripts.
* **NPM** (version 6.x or newer): The Node.js package manager, used for managing project dependencies.

## Installation and Setup

To install the project and run it locally, follow these steps:

1. **Clone the repository:**

   ```bash
   git clone https://github.com/AntonyShaga/air-agency-landing.git
   ```

2. **Navigate to the project directory:**

   ```bash
   cd air-agency-landing
   ```

3. **Install dependencies:**

   ```bash
   npm install
   ```

4. **Start the local development server:**

   ```bash
   npm start
   ```

## Usage

After starting the project, it will be available at `http://localhost:8080`. You can use this URL to preview the landing page and ensure it displays correctly. You can also make changes to the project files and see updates during development.

## Features

* **Responsive Design:** The page is designed to work across desktop, tablet, and mobile devices.
* **Interactive Slider:** The hero section includes an interactive image slider with navigation controls and changing content.
* **Agency Services:** Dedicated sections present the agency's services, expertise, and business approach.
* **Testimonials:** Client testimonial cards showcase feedback and company information.
* **Contact Form:** Visitors can enter their email, name, and message through the contact form.
* **Navigation:** Header and footer navigation provide quick access to the main sections of the page.
* **Accessibility:** Semantic HTML, labels, alternative text, and ARIA attributes are used throughout the interface.

## Technologies Used

This project was built using the following technologies:

* **HTML5:** For structuring the content on the web page, ensuring semantic and accessible markup.
* **CSS3:** For styling the web page, including layout and responsive design features.
* **Sass:** A CSS preprocessor that helps to write cleaner and more maintainable CSS with features like variables, nested rules, and mixins.
* **JavaScript (ES6):** For adding interactivity and dynamic functionality, including the slider and other user interactions.
* **Node.js:** For running the development environment and project tooling.
* **NPM:** For managing project dependencies and scripts.
* **Parcel:** A web application bundler used for building and running the project.
* **Git:** For version control and tracking changes to the codebase.
* **GitHub:** For hosting the repository, project source code, and deployed landing page.
